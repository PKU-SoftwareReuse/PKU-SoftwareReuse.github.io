# 首页图片槽位

将图片按下列文件名放入本目录，Jekyll 构建时会自动替换当前的图形占位内容，无需修改页面代码。页面会依次识别 `.webp`、`.jpg`、`.png`，因此可以直接上传 PNG 或 JPG。

- `hero.webp`：首页首屏主视觉，建议 1920 x 1200 或更大，主体位于画面右侧。
- `team-group.webp`：团队合影，建议 1600 x 1000，横向构图。
- `featx.webp`：FeatX 项目界面，建议 1200 x 750。
- `flowgen.webp`：FlowGen 项目界面，建议 1200 x 750。
- `knowledge-graph.webp`：软件知识图谱或系统界面，建议 1200 x 750。

优先使用 WebP；单张图片建议控制在 500 KB 以内。
